# ML1503 – Web Programming (Lab Integrated)
## Fast Lab Import & Solutions Manual

All 7 syllabus experiments are stored as single files directly in the root directory: **`exp1`** through **`exp7`**.
For experiments with multiple files (Exp 2, 3, 6, 7), the files are clearly labeled inside so you can copy-paste them into separate files.

---

### Direct 1-Line Import Commands

| Exp | Description | Fast `curl` Import Command |
| :---: | :--- | :--- |
| **exp1** | HTML Elements | `curl.exe -O https://raw.githubusercontent.com/jeethgame/web-lab/main/exp1` |
| **exp2** | CSS Types & Selectors (`exp2.html`, `style.css`) | `curl.exe -O https://raw.githubusercontent.com/jeethgame/web-lab/main/exp2` |
| **exp3** | Validation, Slideshow & Quiz (`3_validation.html`, `3a_slideshow_clock.html`, `3b_quiz.html`) | `curl.exe -O https://raw.githubusercontent.com/jeethgame/web-lab/main/exp3` |
| **exp4** | Angular Directives (`exp4.html`) | `curl.exe -O https://raw.githubusercontent.com/jeethgame/web-lab/main/exp4` |
| **exp5** | AngularJS Shopping Cart (`exp5.html`) | `curl.exe -O https://raw.githubusercontent.com/jeethgame/web-lab/main/exp5` |
| **exp6** | Supermarket CLI & Angular Table (`6a_search.js`, `6b_table.html`) | `curl.exe -O https://raw.githubusercontent.com/jeethgame/web-lab/main/exp6` |
| **exp7** | Express REST API & AJAX Client (`server.js`, `client.html`) | `curl.exe -O https://raw.githubusercontent.com/jeethgame/web-lab/main/exp7` |
